# Мои расходы

Сайт для учёта расходов: дневной лимит, статьи расходов, круговая диаграмма, план накоплений.

## Как выложить на GitHub Pages
1. Создайте репозиторий на github.com (например, `rashody`).
2. Загрузите в него файл `index.html` (Add file → Upload files → Commit).
3. Settings → Pages → Source: *Deploy from a branch*, ветка `main`, папка `/ (root)` → Save.
4. Через минуту сайт будет по адресу `https://ВАШ-НИК.github.io/rashody/`.

Данные хранятся в браузере. Кнопка «Скачать копию» сохраняет их в файл, «Загрузить копию» переносит на другое устройство.
